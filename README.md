# ERICA_X_MODULABS_CV

- 한양대학교 ERICA x 모두의연구소 **컴퓨터비전 (중급)** 과정(2026.09.01 ~ 2026.10.23)에서 진행하는 실습 프로젝트와 피어리뷰를 관리하는 Repository입니다.
- 실습 프로젝트별로 폴더를 두고, 각 폴더에는 결과물 노트북(`.ipynb`)과 피어리뷰 템플릿(`README.md`)을 넣습니다.
- 개별 실습 제출 시에는 해당 폴더의 `.ipynb` 파일 URL을 제출합니다.
- 주의: 폴더 구성은 배포된 과정별 시간표를 기준으로 하며, 시간표가 바뀌면 함께 수정합니다.
