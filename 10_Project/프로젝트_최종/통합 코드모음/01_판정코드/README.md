# 01_판정코드 · 첫 판정 서버와 실험 도구 (담당: 박서준, 판정 규칙 설계: 황예성)

1차 회의(10/15) 기준으로 만든 판정 코드입니다. 라즈베리파이 스트림이나 영상 파일에서 사람을 찾고, 직접 그린 다각형 감지 영역 안에 사람이 있는지로 신호등 색(빨강 사용 중 · 노랑 자리 비움 30분 미만 · 초록 30분 이상)을 정합니다. 2차 회의 전까지 판정 규칙과 모델을 검증하는 데 썼고, 최종 통합 실행 프로그램은 [06_통합실행](../06_통합실행)입니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `server.py` | 판정 서버. 정해진 간격마다 사람을 찾아 감지 영역 안 사람 유무로 색을 정하고, 신호등 주소로 POST를 보냅니다. 상태가 바뀐 순간의 화면은 사람을 모자이크해 저장하고, 판정 기록을 CSV로 남깁니다 |
| `capture.py` | 스트림이나 영상에서 N초마다 프레임을 저장합니다 |
| `zone.py` | 첫 프레임 위에서 클릭해 감지 영역(다각형)을 JSON으로 저장합니다 (왼쪽 클릭 꼭짓점 추가, 오른쪽 클릭 삭제, Enter 저장, Esc 취소) |
| `zone_1차.json` | 1차 룸 영상용 감지 영역 (960×540 화면 기준) |
| `compare.py` | 프레임 폴더에 YOLO 모델을 하나씩 돌려 사람·테이블 검출 결과를 CSV로 저장합니다 (모델 비교용) |
| `1차_영상_결과.csv` | `compare.py`로 1차 룸 영상 659장(2초 간격)을 모델 15종에 돌린 결과 |
| `realtime/live.py` | 스트림, USB 카메라, 영상에 YOLO를 실시간으로 돌려 화면에 보여 줍니다 (q 또는 Esc 종료) |

## 실행

```bash
pip install ultralytics opencv-python

# 감지 영역 그리기
python zone.py 1차.mp4 --out zone.json

# 판정 (맥은 --device mps, 윈도우·리눅스는 --device cpu)
python server.py 1차.mp4 --zone zone_1차.json --interval 2 --log log.csv --device cpu

# 시연: 초록 기준을 1분으로 줄이고 신호등으로 색 보내기
python server.py <스트림 URL> --zone zone.json --limit-min 1 --led-url http://신호등주소

# 실시간 인식 화면 (0 = USB 카메라)
python realtime/live.py 0 --zone zone.json
```

| `server.py` 옵션 | 기본값 | 뜻 |
|---|---|---|
| `--model` | yolo26s | 검출 모델 |
| `--th` | 0.30 | 사람으로 인정하는 신뢰도 |
| `--confirm` | 2 | 몇 프레임 연속 잡혀야 사용 중으로 볼지 |
| `--interval` | 5.0 | 판정 간격(초) |
| `--limit-min` | 30 | 초록불로 바꾸는 자리 비움 시간(분) |
| `--led-url` | 없음 | 신호등 색을 POST로 보낼 주소 (없으면 화면에만 출력) |

- 정상 동작 기준: 1차.mp4를 `--interval 2` 기본 설정으로 돌리면 빨강 188장, 노랑 471장이 나옵니다. 검증 결과는 [02_데이터·실험/EXPERIMENTS.md](../02_데이터·실험/EXPERIMENTS.md) 2절에 있습니다.
- 스트림이 끊긴 시간은 자리 비움 시간에 넣지 않습니다. 끊김을 "사람 없음"으로 세면 공부 중인 방에 초록불이 켜지기 때문입니다.
- `compare.py`는 메모리 측정에 `resource` 모듈을 써서 맥·리눅스에서만 돌아갑니다.
- 1차.mp4는 팀원 얼굴이 나와 저장소에 올리지 않았습니다.

## 함께 쓴 부분

- **판정 규칙은 황예성 설계**입니다. 3색 신호등, 30분 기준, 상태가 바뀐 순간만 모자이크해 1일 보관하는 규칙은 1주차에 황예성이 만든 MVP 판정 코드([1주차/3D테스트](https://github.com/hwang-ye-song/MODU_CV/tree/main/프로젝트_오픈스페이스_알박기감지/1주차/3D테스트))를 1차 회의에서 팀 규칙으로 정한 것이고, 박서준이 이 규칙으로 판정 서버를 구현했습니다.
- **감지 영역**은 이 폴더의 다각형 방식(`zone.py`, 박서준)을 손으로 그리지 않도록, 황예성이 SAM 테두리 방식으로 바꿨습니다 → [04_BASE_MODEL](../04_BASE_MODEL), [06_통합실행](../06_통합실행). `server.py`와 `zone.py`는 바꾸지 않았습니다.
- 황예성이 파인튜닝한 모델 v2는 박서준이 정답 659장으로 다시 검증했습니다(학습에 안 쓴 구간 131/132).

> 이 README는 저장소를 정리하면서 코드의 설명(docstring, 옵션)과 팀 실험 기록을 모아 추가했습니다.
