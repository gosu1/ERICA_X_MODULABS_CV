# 오픈스페이스 알박기 감지 시스템 · 팀 알박기 척결

한양대 ERICA 융합교육관 스터디룸 14개에서 짐만 두고 30분 넘게 자리를 비운 룸을 카메라로 찾아, 문 위 신호등 색으로 알려 주는 시스템입니다. 학교에 판매하는 B2B 서비스로 설계했습니다.

## 한눈에 보기

- **문제**: 학교에는 "30분 넘게 비운 룸은 짐을 옮기고 써도 된다"는 규칙이 있지만, 방금 온 학생은 짐 주인이 언제 나갔는지 알 수 없어 규칙을 쓰지 못합니다.
- **해결**: 룸마다 천장 카메라 1대, 교내 PC 1대가 1초마다 판정해 문 위 신호등 색을 바꿉니다. 얼굴은 보지 않고 영상은 저장하지 않습니다.
- **고객과 사용자**: 비용을 내는 고객은 학교 운영 담당, 매일 보는 사용자는 학생입니다. 모든 선택은 ① 정확도·속도 ② 비용 ③ 운영·유지보수 ④ 개인정보 기준으로 판단했습니다.

## 판정 규칙

| 신호등 | 상태 | 학생 행동 |
|---|---|---|
| 🔴 빨강 | 감지 범위 안에 사람이 있음 | 사용 중 |
| 🟡 노랑 | 사람이 없고 30분 미만, 짐이 남아 있음 | 짐에 손대지 않음 |
| 🟢 초록 | 사람이 30분 넘게 없음 | 짐을 룸 앞 바구니로 옮기고 사용 |
| 🟢 초록 | 사람도 짐도 없는 빈 책상 | 기다리지 않고 바로 사용 |

- 감지 범위: 빈 룸에서 YOLO26s v2가 찾은 테이블 박스를 SAM에 넣어 테이블 테두리를 따고, 짧은 변의 15%만큼 부풀립니다. 사람 박스가 이 범위와 10% 이상 겹치면 재석입니다.
- 사람이 2초 연속 보여야 재석, 10초 연속 안 보여야 부재로 봅니다.

## 결과

| 항목 | 값 |
|---|---|
| 최종 모델 | YOLO26s 파인튜닝(v2), 학습 데이터 727장(학습 637 + 검증 90) |
| 학습에 안 쓴 영상 기준 | 테이블 2% → 100%, 엎드린 사람 92.9% → 100%, 사람 100% |

| 비용 | 초기 207만 원, 구독 룸당 월 1.5만 원(연 252만 원 = ERICA 학생지원비의 0.02%) |

## 시도했다가 제외한 것

| 시도 | 제외한 이유 |
|---|---|
| 3D 디지털 트윈으로 검증 | 엎드린 사람 48.9%로 실제 사진(6/6)과 달라 중단, 실제 룸 영상으로 검증 |
| 사전학습 모델 그대로 사용 | 16종 중 테이블과 엎드린 사람을 둘 다 잡는 모델이 없음 → 파인튜닝 |
| 1차 파인튜닝(테이블 위주) | 사람을 잊음(100% → 68%) → 사람 데이터를 넣은 v2 |
| 합성 데이터로 학습 | 모델이 이미 잡는 장면이라 학습에서 제외, 약점(후드 쓰고 엎드린 사람) 찾기에 활용 |
| 사각형 박스 감지 범위 | 통로까지 덮음 → SAM 테두리 +15%, 겹침 기준 25% → 10% |
| 룸별 라즈베리파이 | 1장 2,832ms, 최고 81.3°C로 1초 간격 판정 불가 |
| 클라우드 GPU | 월 약 60만 원, 영상이 학교 밖으로 나감 |

## 한계와 다음 단계

- 현장 데이터가 룸 1곳 영상 22분뿐입니다. 학교 협조를 받아 7일간 실제 룸에서 수집하고, 현장 데이터로 다시 학습한 뒤 시험에 합격하면 14개 룸에 적용합니다.
- 불합격 기준: 관찰 300회 중 주인이 있는데 초록불이 켜진 경우 1건 이상, 또는 빈 룸을 놓친 경우 2% 초과.
- 룸 14개 동시 처리는 노트북 GPU에서 영상을 복제해 시험했습니다(한 바퀴 중앙값 453ms, 1초 간격 가능 → [06_통합실행](프로젝트_최종/통합%20코드모음/06_통합실행)). GTX 1060 실측과 실제 카메라 14대 시험은 아직 하지 않았습니다. 빈 책상 판정은 단위 테스트로만 확인했습니다.
- 고도화: 1층 현황판.
